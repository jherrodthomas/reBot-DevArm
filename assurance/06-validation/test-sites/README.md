# Test benches and session logs

One file per test bench (`<bench>.md`: the bench, the fixing, the marked floor area, the pendant position, the
PSU and its disconnect, exits) and one log per session (`<YYYY-MM-DD>-<bench>.md`) in the format of
[WP-V-07 §5](../WP-V-07-test-operations.md#5-test-log).

No bench is defined and no powered session has been run under the fork's control.
