## 1. Purpose

How a change is requested, classified by the safety-relevant file list, impact-analysed (WP-M-11 format, records under `07-supporting/impact/`), reviewed, verified and merged; what the pull request template asks for.

## 2. Change classes

NSR, SR-T, SR-Q, SR-A and what each needs.

## 3. Procedure

Request, impact analysis, review, verification, merge, record update.

## 4. Records

The impact folder and the pull request as the record.
